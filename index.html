A LITTLE GUIDE

欢迎来到知序

给自己留一点时间，让知识慢慢生长。

01

三种模式，独立保留进度

背题直接显示答案，不计成绩；练习确认选择后在选项中标出答案；考试交卷后统一显示分数和逐题解析。各单元、错题和随机卷分别保存进度，默认继续，勾选「重新开始」才重置。

02

错题按自己的规则复习

答错自动收入错题本，可设置累计答对 1～100 次后移出，也能确认后手动移出。错题本支持独立随机组卷。原文有格式疑点的题暂不判分，编辑修正后再练。

03

组卷、计时与题库版本

支持不计时、正计时、倒计时。随机卷可按单元、题型或两者叠加抽取，默认题型比例为60% / 30% / 10%，选项顺序不变。JSON 导入保留为同一本读本的独立版本，可随时切回默认版；各版本的进度与错题独立。

题目修改、解析和学习记录保存在当前浏览器，可用 JSON 导入导出。只有主动调用并确认后，才向你配置的 API 发送当前这一道题；不发送整本题库，分析不会自动修改答案。API 密钥不会进入备份。
