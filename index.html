A LITTLE GUIDE

欢迎来到知序

给自己留一点时间，让知识慢慢生长。

01

三种模式，独立保留进度

背题直接显示答案，不计成绩；练习确认后判分；考试所有题型均选择后停留，点击下一题或选题切换，交卷后只显示错题与未作答题解析。收藏与选题之间的“掌握”按钮可标记或取消已掌握题目；在“我的收藏”中切换到“已掌握题目”查看。掌握标记在背题、练习、考试中均可使用，不改变作答或成绩。选题按钮可展开题号自由跳转：考试仅标记已答蓝色、未答灰色；练习另标记答对绿色、答错红色；背题不标记状态颜色。练习和考试未答完提交时会提醒。继续按钮直接恢复进度，重新开始需确认并重新设置。

02

错题按自己的规则复习

答错自动收入错题本，可设置累计答对 1～100 次后移出，也能确认后手动移出。错题本支持独立随机组卷。原文有格式疑点的题暂不判分，编辑修正后再练。

03

组卷、计时与题库版本

支持不计时、正计时、倒计时。各入口设置均可同时勾选去除多选题全选、判断题正确、已掌握题目；按当前修订答案筛选后再抽题，库存不足时提示，不会擅自调整比例。继续进度保留原题序，重新开始才应用新条件。已掌握标记与排除条件随学习进度自动保存、按版本隔离，导出时请勾选学习进度。随机卷可按单元、题型或两者叠加抽取，默认题型比例为60% / 30% / 10%，选项顺序不变。JSON 导入保留为独立版本；题目和进度自动续存为本机草稿，在顶部设置中手动保存命名版本，可分别勾选题库内容、解析和学习进度。各版本进度独立；默认与自定义单元均可改名，单元和题目删除需两次确认，仅影响当前版本。删除会清理相关记录及包含已删题的练习进度。内置基准采用 2026-09-23 JSON 修订，正确答案以修订后的答案字段为准，解析原样保留，原始读本仅作对照。历史成绩不追溯改分。保存版本时不勾选题库内容，可新建完整默认修订版本。

题目修改、解析和学习记录保存在当前浏览器，可用 JSON 导入导出。只有主动调用并确认后，才向你配置的 API 发送当前这一道题；不发送整本题库，分析不会自动修改答案。API 密钥不会进入备份。
