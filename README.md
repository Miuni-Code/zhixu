知序版本更新说明
题库修订 · 已掌握管理 · 练习筛选升级
本次更新同步了官方答疑表格中的题目修订内容，并新增“已掌握题目”和练习排除功能，方便大家按自己的掌握情况安排复习。

一、题库错误修订与解析更新
根据官方答疑表格，更新相关题目的答案、题型、选项及解析说明。

本次共涉及 23 道题目，其中：

修订 7 道题目的正确答案；
调整 2 道题目的题型；
更新 2 道题目的选项内容；
补充或更新 23 道题目的解析。
以上修订项目存在重叠，题库总量仍为 1047 题。

更新后，答题判分与相关筛选均以最新修订答案为准。解析中如保留旧读本答案作为对照，请以题目展示的当前修订答案为准。

二、新增“已掌握题目”
“我的收藏”页面新增“已掌握题目”入口，可集中查看和复习已经熟练掌握的题目。

答题界面底部新增“掌握”按钮，位置为：

收藏 → 掌握 → 选题

点击即可标记为已掌握，再次点击可取消。背题、练习、考试模式均支持使用。

掌握标记与收藏、错题记录相互独立，不会自动修改成绩、清除错题，也不会将题目从当前练习中移走。

三、新增三类练习排除条件
在练习设置中，可按需勾选：

去除多选题答案为全选的题目
去除判断题答案为“正确”的题目
去除已掌握题目
三个条件可以单独使用、任意组合，也可以全部勾选。

该功能覆盖分单元练习、随机组题、收藏与已掌握复习、错题复习及组卷、每日练习和单题练习，并适用于背题、练习、考试三种模式。

设置时会显示筛选后的可用题量。随机组题会先筛选、再按比例抽题；若剩余题量不足或无法满足所设比例，会明确提示，不会擅自调整配额或重复抽题。

四、进度保存与使用提醒
已掌握标记和排除条件会自动保存在当前浏览器中，各题库版本独立保存。
保存版本或导出 JSON 时，勾选“学习进度”，即可一并保存掌握标记和筛选设置。
新的排除条件在新建或重新开始练习时生效；点击“继续”仍恢复原有题目和进度。
已有历史成绩保留，不追溯改分；修订后不再适用新题型的旧选择，需要重新作答。
建议更新前先导出一份包含学习进度的 JSON 备份。
